# Contenido de redes · Monterra Solutions

Aquí vive el material listo para publicar en Instagram: las imágenes, los videos y el
texto de cada publicación. Una carpeta por cliente.

No se guardan los archivos de trabajo (los HTML editables, las plantillas ni las fotos
originales). Eso se queda en la Mac, en `Portafolio Monterra/`. Este repo es solo lo que
se sube tal cual.

## Clientes

- [`tony-de-olarte/`](tony-de-olarte/) — diseño floral, Monterrey. Lanzamiento de su sitio.

## Cómo descargarlo

Con el botón verde **Code → Download ZIP** en GitHub, o desde la terminal:

```bash
git clone https://github.com/MonterraSolutions/contenido-redes.git
```

## Cómo se organiza cada cliente

```
cliente/
├── README.md              el texto de cada publicación, listo para copiar
├── post-01-<nombre>/      una carpeta por publicación
├── post-02-<nombre>/
└── post-03-<nombre>/      si es video, aquí van el mp4 y su portada
```

Son **tres publicaciones por cliente**. Cada una vive en su propia carpeta con
todo lo que necesita, y el README de arriba lleva el texto de las tres.

Al agregar contenido nuevo de un cliente que ya está, se pone en su misma carpeta y se
anota en su README. Si es un cliente nuevo, se crea su carpeta con la misma estructura.
